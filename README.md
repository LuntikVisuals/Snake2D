# Snake2D (2.0.0-beta)

2D Змейка для Android (Kotlin + Jetpack Compose).

> **BETA** — игра в открытом бета-тесте. Баги и незавершённые фичи ожидаемы.

## Режимы
- Классика, Скорость, Без стен, Препятствия, На время
- **Поедание** — большая карта, 4 AI, персонажи со способностями

## Сборка
```bash
./gradlew assembleDebug
./gradlew testDebugUnitTest
```

JDK 17, SDK 35, minSdk 26.
