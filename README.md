# Snake2D

2D Змейка для Android (Kotlin + Jetpack Compose).

## Режимы
- **Классика** — стены убивают
- **Скорость** — быстрее, больше наград
- **Без стен** — тороидальное поле
- **Препятствия** — статичные блоки на поле
- **На время** — 60 секунд, максимум очков
- **Поедание** — большая карта, 4 AI-врага, способности персонажей

## Функции
- Скины, магазин, кейсы с компенсацией дубликатов
- Персонажи: Обычная, Шут, Тор (способности)
- Ежедневная награда и серия входов
- Достижения
- Локальная статистика и история операций
- Пауза, автопауза при уходе в фон
- Локальный + онлайн рейтинг (JSON, только чтение)

## Сборка
```bash
./gradlew assembleDebug
./gradlew testDebugUnitTest
```

## Требования
- JDK 17
- Android SDK 35
- minSdk 26

## Примечание по онлайн-рейтингу
Текущий клиент только скачивает `leaderboard.json`.  
Отправка результатов требует серверного API с валидацией — в клиенте намеренно не имитируется.
